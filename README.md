# legis-lab

An interactive web interface for engaging with and learning about legislative bills brought before the U.S. Congress.

## Sources
Legislation prepared using XML is available starting from 2004. The standardized format provides the opportunity for building a new interface to speak with these documents.
http://xml.house.gov
